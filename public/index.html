edgeone-s3-site-statistics

站点访问统计 · EdgeOne Pages Edge Function + S3

入口

/dashboard.html 自检面板，展示当前计数
/api/health 配置检查：缺哪些变量、S3 是否可用

接口

POST /api/hit?p=/path/ 记录一次访问，返回 204
GET /api/stats?p=/path/ 站点与页面计数，JSON
GET /jsonp?callback=X&p=/path/ 同上，JSONP 形式
POST /api/aggregate?token= 强制重算聚合（需 STATS_TOKEN）

数据存放在你自己的 S3 兼容存储中；访问日志只保留 16 位访客哈希，不存 IP。
